📚 Key Learnings

What I Learned Building This

🧠

Zero-Shot vs Supervised Learning

Understanding the practical difference between models that require large labelled datasets versus those that generalise from descriptive language — a fundamental shift in AI paradigm.

🔗

Multimodal Embedding Spaces

Learning how CLIP creates a joint image-text vector space, and how cosine similarity can replace traditional classification heads to achieve flexible, open-vocabulary prediction.

🎨

Production-Quality UI Design

Moving from functional to beautiful — implementing a full design system with CSS variables, dark mode, responsive layouts, and micro-interactions that feel like a real product.

📷

Color Space Analysis

Discovering how HSV (Hue, Saturation, Value) separates color from brightness far better than RGB for detecting produce defects — a key insight from computer vision literature.

⚡

Inference Optimisation

Learning to use torch.no_grad(), model caching, and preprocessing pipelines to reduce end-to-end latency from 8+ seconds to under 2 seconds on CPU.

🧩

System Integration

Connecting an AI model, computer vision pipeline, nutrition database, web framework, and template engine into a coherent, maintainable application — full-stack AI development in practice.
